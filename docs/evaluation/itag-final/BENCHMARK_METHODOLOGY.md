# Evaluation protocol

**Unit.** A new case contains one authenticated bounded task, two historical actions, one tool observation and a terminal proposal. Amounts in the fixture are USDC with six decimals. Prior receipt states are materialized by the existing MOCK evidence builder. Histories are supplied to the terminal decision; the benchmark does not run a live agent between every event. Pairs share the task theme. The 24 authored rows consist of 12 benign controls, four explicit conflicts with an exclusive objective, and eight policy or evidence-integrity interventions. The last group includes operational states that can arise innocently. The first blocked step is the ordinal of the candidate transaction. It does not localize first psychological influence.

**Labels.** Read `input` and `truth` separately in LONG_HORIZON_SCENARIOS.jsonl. The label and reason were authored before provider calls. A different use of WAVAX matters only where the task explicitly restricts its purpose and the candidate declares another purpose. A market note alone does not change authorization. The benchmark supplies no causal tool-to-proposal edge for similar wording. No row is an imported sample or independently reviewed label. Semantic completion of a qualitative goal and true delayed contamination across intervening actions have limited coverage. The original 30 rows remain in fixtures/itag/scenarios.csv.

**Comparison.** For each row, the production planner fixture, builder, wallet checks, economic risk evaluation, intent, graph, model outputs and SDE inputs are constructed once. Five calls to the SDE vary only wallet/Shield/temporal/hybrid inputs. A = wallet, B = wallet + action Shield, C = wallet + deterministic ITAG, D = B + deterministic ITAG, E = full fusion. There is no live switch to select A–D. MOCK financial inputs and simulated history make these approval comparisons pre-sign counterfactuals. They do not independently run five forks, SMT proofs, signatures or contracts. Full enforcement is separately exercised with Anvil. Upstream Shield vetoes short-circuit semantic inference; this runner does not credit a skipped graph call.

**Leakage.** The evaluator receives the same opaque session ID for every row, only the operational input is forwarded, and each run has a fresh temporary database. The fixture provider is scripted separately. A regression freezes runtime UUID generation, changes the hidden label and checks every model-bound message hash. Pair members share a split. Both splits reuse the same wallet and budget grammar. Fourteen rows are marked held out; model conclusions do not generalize to independent protocols. The live subset deliberately covers three pairs. Only one pair in that subset is held out.

**Measurement.** Each table includes raw counts. For intervention metrics, REPLAN, REJECT and ESCALATE all withhold approval. Report explicit semantic detection separately from refusal due to unavailable evidence. Seven conditions are tracked in EXPLANATION_REVIEW.json, with no credit for unresolved factual review. The model can guess the correct semantic judgment and still fail the evidence gate. A null reference check means there was no validated finding to score. Cross-checking the graph verifies structured facts, not the truth of a free-text explanation. The nine structured checks include projection consistency and independent input checks for amount, purpose, objective and confirmed spend.

**Provider budget.** DeepSeek Flash, primary provider only, three paired scenarios per pass, at most eight logical completions per row. First pass used v2.2 with retry disabled. Replication used v2.3 with an optional structured factual-claims schema and at most one configured retry; only known evidence linkage can be repaired, while preserving semantic core. The same cases were repeated to test output validation, not to enlarge the sample. Each pass actually used 24 calls. Raw provider text is omitted; reports keep parsed Shield results, validated findings, actual provider attempts, usage, context hashes and reason codes. Replication also records the proposed verdict before validation. Wording and prompt changes between passes preclude a controlled causal estimate of prompt improvement.

**External research.** Repository structure and top-level license metadata were inspected. Zero external samples entered the benchmark, so external examples, scores and dataset licenses do not transfer to these fixtures. Intent/transaction data, configurable agent test environments, and labeled trajectory corpora would require distinct adapters, license review at dataset-file level and separate splits before reuse.
