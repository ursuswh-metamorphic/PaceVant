# temporal — Intent-Aware Temporal Action Graph (ITAG)

> **DOC STATUS: MODULE_REFERENCE** - local interface/contribution reference, not a live readiness certification. The [current system design](../../../../../docs/AI_Treasury_Security_System_Design_v2.1.md) owns the complete architecture/status; old reports linked below remain checkpoint-scoped.

Owns authenticated per-intent terms, revision/cancellation, cross-workflow budgets and ordered dependencies. The deterministic verifier reads reservations and reconciled outcomes from SQLite; the semantic evaluator consumes the graph using the active Task Shield provider. Model output can veto or escalate, never create authorization.

Files: `models.py` graph/spec/assessment DTOs; `intent_spec.py` scope validation; `storage.py` additive immutable history and atomic approval checks; `graph_builder.py` provenance graph; `verifier.py` budget/order/outcome gates; `semantic_evaluator.py` bounded LLM assessment; `fusion.py` strongest verdict; `explainer.py` explanations; `service.py` feature orchestration; `api.py` operator-authenticated endpoints and viewer. Shared `IntentSelection` is defined in core to preserve dependency direction. Scripted replay infrastructure lives in `operations/itag_benchmark.py`, not in this runtime module.

Workflow evaluation saves an assessment hash. The attestor reservation and final SUBMITTING transaction revalidate its hashes, active revision, history/ledger, task revision and PRE snapshot links. Model calls occur outside SQLite write transactions. Economic risk, PGS proof and Solidity checks remain mandatory. Existing V2 proof hashes and contract ABI are unchanged.

`PACEVANT_REQUIRE_ITAG=0` preserves existing workflow compatibility; the current Fuji demo env/template uses `1` to require a structured intent on all workflows/signing paths. ITAG workflows also require active Task Shield and an actual operator credential even in MOCK. The dashboard/CLI create an operator-authenticated exact-amount one-shot intent before starting the workflow. `/itag` provides the read-only graph viewer when frontend serving is enabled. Viewer assets live at `frontend/itag*`; token stays in tab memory.

Verify with `python -m pytest backend/tests/control/test_itag.py backend/tests/execution/test_itag_unified.py -q` inside the locked environment. Scripted semantic tests are not evidence of model accuracy. V2 Anvil integration covers successful proof/sign/swap/receipt and repeated-intent rejection in individual and pipeline modes, plus fail-closed behavior when output exceeds budget. Real provider/Fuji evidence is recorded separately in [the live runbook](../../../../../docs/demo/FUJI_ITAG_LIVE.md); historical merge limitations remain in [the integration checkpoint](../../../../../docs/integrations/ITAG_MAIN_SYNC.md).


Semantic citation repair is bounded to one extra request when enabled by `PACEVANT_SHIELD_RETRIES`. It applies only to already-known evidence refs missing their cited graph source node. Fabricated identities fail immediately. The semantic core (verdict, source, goal-drift flag, task relationships and uncertainty presence) cannot change. Provider traces/usage include both calls; deadline and context budgets remain enforced. Regressions: `backend/tests/control/test_itag_citation_repair.py`.
