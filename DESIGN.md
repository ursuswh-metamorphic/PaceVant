# PaceVant — Security Editorial

This pass refines the established light/cobalt product identity, with an editorial Overview composition. It does not replace the operational Demo design system.

## Scope and intent
Overview persuades judges to inspect the working security workflow. Visual confidence comes from a clear architectural boundary and precise typesetting, rather than decorative trust badges or invented performance numbers.

## Overview tokens
- Canvas: #F7F9FC; paper #FFFFFF; ink #171A24; supporting text #58677B; muted #758398; rule #DFE5EE.
- Accent: established cobalt #3861D8, hover #2851C5; pale #EDF2FF. No decorative green approval states.
- Typography: locally bundled Inter Variable, with Vietnamese coverage. Headline 60–64 desktop, 36 mobile, weight 650–700, -0.045em. Section 30/26, body 15–16, metadata 11–12.
- Spacing: 8px base; 24px interior rhythm; 72–88px section separation. Content 1120px, headline measure 900px, paragraph 650px.
- Surfaces: architecture panel only uses a 16px boundary; editorial sections use rules and aligned columns instead of repeated cards. Buttons remain shared shadcn/Radix patterns.
- Motion: existing restrained page transition, no autonomous progress or illustration animation.

## Composition
Centered three-clause hero and one 56px CTA. A static labeled architecture ribbon clarifies propose → verify → execute; no live states or fake data. An asymmetric problem/solution editorial section follows. Four numbered process columns share one rule, not four floating cards. Responsive stacked reading order and visible keyboard focus.

## Research decisions
UI UX Pro Max's local design-system search recommended Swiss minimalism, authority and a clear conversion path. Retain those hierarchy/accessibility principles; reject suggested amber/purple palette and sales CTA because they conflict with the confirmed PaceVant brief. Impeccable's cognitive-load and polish rubric guides review: single action, meaningful symbols, no repeated visual hierarchy, adequate text contrast and locale wrapping.
